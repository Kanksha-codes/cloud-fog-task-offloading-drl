# Prioritized Task Offloading in Cloud–Fog Systems using Deep Reinforcement Learning

This project implements a DRL-based framework to optimize task offloading decisions between fog and cloud environments.

## Objective
To minimize latency and improve resource utilization using intelligent task scheduling.

## Algorithms Used
- Deep Q Network (DQN)
- Advantage Actor-Critic (A2C/A3C)
- Proximal Policy Optimization (PPO)

## Workflow
1. Environment modeling
2. State and action space definition
3. Reward function design
4. Policy training and evaluation

## Results
DRL-based policies improved task scheduling efficiency compared to baseline methods.
